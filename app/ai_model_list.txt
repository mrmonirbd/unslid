================================================================================
  AI MODEL PROVIDER REFERENCE — AiPresentation SaaS
  Use this as a reference when configuring AI models in the Admin panel.
  Admin panel: http://localhost:3000/admin → AI Model Configuration section
================================================================================

HOW TO USE:
  1. Log in as admin@aipresentation.dev
  2. Go to http://localhost:3000/admin
  3. Scroll to "AI Model Configuration"
  4. For each plan (Free / Pro / Team), set the Provider, Model, API Key
  5. For providers marked [OpenAI-compatible], select "Custom (OpenAI-compatible)"
     and fill in the Base URL + Model fields
